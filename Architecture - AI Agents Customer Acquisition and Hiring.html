Layer 1
🏢 TENANTS / COMPANIES (Workspaces) ▼
Company A Gmail/Drive | Company B Gmail/Drive | ...
Gmail Inbox Inbound emails per company, mapped to tenant
Google Drive Templates, resumes, contracts per tenant
Workspace Isolation Each company = separate data silo
Inbound events & Outbound triggers
Layer 2
⚡ n8n (SELF-HOSTED) — THE CONDUCTOR ▼
Watches Gmail/Drive • Schedules, retries, routes • Calls your APIs • Waits for approval
Triggers Watch Gmail, Drive uploads, scheduled runs, manual buttons
Orchestration Step ordering, routing, retries, rate limiting
Integrations Gmail API, Drive API, your HTTP endpoints
Waiting Pause workflows until approval flag changes
Example Flows
New Email → Fetch → Call AI → Save → Notify UI
Lead CSV → For Each → Call AI → Queue Drafts → Schedule
Resume PDF → Extract Text → Call AI → Score → Shortlist
HTTP calls / Webhooks
Layer 3
🧠 YOUR CODE (APIs) — THE "AI BRAIN" ▼
Business logic, AI intelligence, policy enforcement, governance
1. Tenant & Policy Service Inbox → tenant mapping • Allowed Drive folders • Template registry • Guardrails (what AI can/can't say)
2. Intelligence Service (LLM) Classify, score, summarize, suggest action, draft • Strict JSON outputs • Confidence gating • Redaction before LLM
3. Document/Template Service Fetch template snippets (allowlisted) • Store docs back to tenant Drive • Version metadata
Read / Write
Layer 4
🗄️ OPERATIONAL DB (CENTRAL) ▼
Single source of truth for all operational state
Email State Thread metadata, classifications, priority scores, summaries
Drafts & Approvals Draft versions, approval status, edit history
Hiring Pipeline Candidate records, fit scores, interview state, decisions
Audit Logs Sources used, who approved, what was sent, timestamps
Query / Update
Layer 5
🖥️ REVIEW UI (DASHBOARD) ▼
Human-in-the-loop interface for review, edit, and approval
Priority Queue Cross-company unified queue, sorted by score
Summaries One-line executive summaries, suggested actions
Draft Editor Edit draft → Approve → Send
Hiring View Candidate shortlist, fit scores, scheduling actions
Approved Actions
Layer 6
📤 SENDING (via n8n + Gmail) ▼
Executes approved sends, completes the loop
Gmail API Send n8n calls Gmail API to send approved drafts
Reply Loop Replies come back to inbox and re-enter the flow
↻ Replies loop back to Inbox → n8n triggers again

What Lives in n8n vs What Lives in Code

Clear boundaries for maintainability and governance

n8n Orchestration / Plumbing
The "when" and "in what order"
Triggers & Intake
New email arrives in Gmail inbox
New file uploaded to Drive folder (resumes, templates)
Manual trigger buttons ("run outreach sequence now")
Scheduled runs (daily digest at 9 AM, follow-up checks)
Workflow Coordination
Step ordering: Fetch → Call API → Store → Notify
Routing: if "Sales" then path A, if "Hiring" then path B
Retries: automatic retry on transient failures
Rate limiting: simple throttling (sleep/wait between calls)
Waiting: pause workflow until approval state changes
Notifications: Slack/Email alert if workflow fails
Integrations
Calling Gmail API to fetch/send
Calling Drive API to fetch/upload
Pushing updates to your DB endpoints
Pulling lead lists from Google Sheets
⚠️ What NOT to do in n8n
Don't embed complex tenant logic in n8n
Don't store secrets scattered across many workflows
Don't implement "policy rules" in 50 different nodes
Your Code Business Logic / Brain / Governance
The "what does this mean" and "what should we do"
Tenant Isolation & Policy
Inbox → tenant mapping (source of truth)
Allowed Drive folders (whitelist) per tenant
Template registry + "approved only" enforcement
"Never promise pricing unless from approved sources"
Confidence gating rules (if confidence < X → human review)
AI Logic
Classification schema (function/intent/urgency/impact)
Priority scoring rules (deterministic, auditable)
Zero-context summarization + format enforcement
Action recommendation (reply/ask/schedule/hold/escalate)
Draft generation: template + variables + brand tone
Redaction/minimization before sending to LLM
Data & Audit
Operational DB schema and all writes/reads
Draft versioning + approvals tracking
Audit logs: what snippets used, who approved, what sent
Duplicate prevention / idempotency keys
Document Handling & UI
Extract content from templates (Docs/PDF) normalized
Save contracts to correct tenant Drive folder
Priority queue, summaries, draft editor, approvals UI
Candidate shortlist, fit score view, scheduling
📐 Practical Rule of Thumb
If a feature answers...
"When? In what order? What to call next?"
→ Put it in n8n
If a feature answers...
"What does this mean? What should we do? What should we say?"
→ Put it in your code
